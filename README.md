# Simple Google Login + Signup Starter

This repository now contains a very beginner-friendly example for building a simple Google Login / Signup flow with:

- Next.js App Router
- Tailwind CSS
- Supabase
- Google OAuth

## Files to copy into your Next.js project

- `.env.local.example`
- `lib/supabaseClient.js`
- `app/config/page.js`
- `app/login/page.js`
- `docs/auth-system-guide.md`

## Recommended order

1. Create your Next.js project.
2. Install `@supabase/supabase-js`.
3. Copy `.env.local.example` to `.env.local`.
4. Add `lib/supabaseClient.js`.
5. Add `app/config/page.js`.
6. Add `app/login/page.js`.
7. Follow `docs/auth-system-guide.md` for the Supabase + Google dashboard setup.
