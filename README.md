# MegaPrep Question Maker - Auth Starter Guide

This repository now contains a beginner-friendly starter example for building authentication in **Next.js App Router + Tailwind CSS + TypeScript + Supabase**, including **Google OAuth** and **email/password auth**.

## Included example files

- `docs/auth-system-guide.md` - step-by-step explanation
- `lib/supabaseClient.ts` - reusable Supabase browser client
- `components/auth/AuthFormUI.tsx` - UI-only auth form
- `app/login/page.tsx` - login logic using Supabase
- `app/signup/page.tsx` - signup logic using Supabase
- `app/profile/page.tsx` - session example showing current user info
- `.env.local.example` - environment variable template

## Notes

This is a teaching-focused example, so the files contain a lot of comments on purpose.
